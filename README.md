# 🍕 Slice Point — Pizza Shop Website (HTML + CSS + JS)

Ek chhoti si **pizza shop website**, jo humne Instagram Reel mein **Tech Bro Z Code Editor** mein live banayi aur badli.

🌐 Live website: https://nm621532-byte.github.io/pizza-shop-website-techbroz/
🎬 Instagram Reel: https://www.instagram.com/reel/DfLn1omHYnV/

## Isme kya hai?
- Pizzas ki list JavaScript array mein, `map()` se har pizza ka card
- **Add 🛒** button dabao, cart count badhta hai
- Dark mode, orange glow cards, 2 column grid, red buttons
- Naye pizzas add kiye: Farmhouse 🌽 aur Paneer Tikka 🧀

## Khud kaise chalayein?
1. Repo download karo (Code → Download ZIP) ya `git clone https://github.com/nm621532-byte/pizza-shop-website-techbroz.git`
2. `index.html` browser mein kholo — bas!
3. Ya teeno files Tech Bro Z Code Editor (website mode) mein paste karo aur **🌐 Website live karo** dabao.

## Files
- `index.html` — page ka structure
- `style.css` — design (dark mode, cards, grid)
- `script.js` — pizzas ki list + cart
